# ZorviDownloader v1.0.0

Aplicación nativa de descargas de audio y video desarrollada para Zorvi Linux.

## Características
- Interface nativa con paleta Morado (#7138B8) y Negro (#09070D).
- Soporte para enlaces de YouTube, Facebook Reels, Instagram, TikTok, etc.
- Descarga de videos (MP4, WEBM) y audio (MP3, M4A, FLAC).
- Soporte para descargar playlists completas.
- Vista previa de enlaces antes de descargar.
- Botones para Pausar y Cancelar descargas en vivo.

## Requisitos y Uso
Para ejecutar desde el código fuente:
```bash
python3 descargador.py
